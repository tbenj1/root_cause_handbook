# Troubleshooting Checklist

## Gather the Information

* [ ] Confirmed the affected user or users
* [ ] Confirmed the affected device or devices
* [ ] Confirmed where the user is working
* [ ] Confirmed when the issue started
* [ ] Confirmed whether it worked before
* [ ] Confirmed whether one person or multiple people are affected
* [ ] Documented the exact error message
* [ ] Collected a screenshot when it was useful
* [ ] Documented the steps needed to reproduce the issue
* [ ] Documented the business impact
* [ ] Asked what changed before the issue started

## Investigate

* [ ] Reviewed IT Glue or the available internal documentation
* [ ] Reviewed related tickets or knowledge-base articles
* [ ] Checked the available RMM information
* [ ] Reviewed Event Viewer when it applied
* [ ] Checked the related services or processes
* [ ] Used comparison testing to narrow down the issue
* [ ] Researched the exact error message or code
* [ ] Used reliable vendor or technical sources
* [ ] Documented what each test proved or ruled out

## Resolve or Escalate

* [ ] Made one meaningful change at a time
* [ ] Documented each troubleshooting step and its result
* [ ] Confirmed the issue no longer happens
* [ ] Repeated the original task and confirmed it works
* [ ] Received confirmation from the user when possible
* [ ] Documented the cause when it was known
* [ ] Documented the final fix or workaround
* [ ] Updated IT Glue or the knowledge base when needed
* [ ] Included complete notes when the issue was escalated
